Privacy policy

Last updated: October 4, 2026

This policy explains how the rclone backup application ("the application") handles data. The application is a private, non-commercial tool used only by its owner.

Who uses the application

The application has a single user: its owner. It is not offered to the public, and no one else can sign in or use it.

What data it accesses

The application requests only the Google Drive drive.file permission. This allows it to create files in the owner's Google Drive and to access only the files it has created itself. It cannot see, read, change, or delete any other files in the Drive.

How the data is used

The application uploads backup archives from the owner's home server to a dedicated folder in the owner's Google Drive, and removes archives older than 30 days. The data is used for no other purpose.

Sharing and storage

No data is shared with, sold to, or disclosed to third parties. The application does not use analytics, advertising, or tracking. Backup files are stored only in the owner's own Google Drive account.

Use of Google user data

The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be withdrawn at any time from the Google Account under third-party connections. Files already created by the application remain in the Drive until they are deleted.

Changes

If this policy changes, the updated version will be published on this page with a new date.
