rclone backup

A private application used by one person to store nightly backups of a home server in their own Google Drive.

What it does

Every night, a scheduled job on a self-hosted Raspberry Pi creates a compressed backup archive. The open-source tool rclone uploads it to a dedicated folder in the owner's Google Drive. Archives older than 30 days are deleted automatically.

Access and data

The application requests only the drive.file permission, so it can access only the files it creates itself. It cannot see any other files in the Drive. It has a single user, its owner, and no data is shared with third parties.
